# Scenario Practice: Phishing to Credential Compromise

A focused simulation exercising email gateway header analysis, sender verification checks (SPF/DKIM/DMARC), credential harvesting URL dissection, and post-click authentication log correlation.

### Learning Goals
- Identify mismatch between display sender and envelope return-path.
- Recognize credential harvesting landing pages masquerading as SSO logins.
- Detect session anomalies following credential theft.

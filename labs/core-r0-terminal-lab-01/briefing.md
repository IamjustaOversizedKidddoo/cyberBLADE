This is your first time on a real-looking Linux server, through a terminal — no windows, no mouse, just commands. Every security job uses this skill, from SOC analysts reading logs to penetration testers exploring a machine.

**What to do**

1. Find out where you are (`pwd`) and what is around you (`ls`).
2. Someone left a note in a **hidden** file in your home folder. Find it and read it.
3. A backup job writes a verification code at the **end** of a long log file. Read just the last line.
4. Count how many lines of the application log contain **ERROR** — the kind of quick check an analyst does when an app starts failing.

Type `help` in the terminal to see every command this lab understands.

This machine is a simulation you are allowed to explore. Nothing you do here touches a real system.

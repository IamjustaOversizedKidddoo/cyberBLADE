# Scenario Practice: Exposed Service Brute Force

Exercises perimeter authentication triage, differentiation between automated password sprays, brute-force dictionary attacks, and MFA prompt spamming attacks.

### Learning Goals
- Analyze Linux syslog auth.log and Windows Security Event 4625 records.
- Identify MFA fatigue patterns where repeated prompt denials culminate in a compromised user acceptance.
- Verify whether successful logins occurred from anomalous external IP blocks.

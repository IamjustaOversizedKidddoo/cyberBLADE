# BladeQL Query Practice: Log Hunting Fundamentals

Welcome to the **BladeQL Query Practice** lab. In this exercise, you master CyberBLADE's original, pipeline-based investigation language designed for security operations.

### Objectives
1. Complete progressive queries ranging from basic filtering to multi-stage aggregations.
2. Practice threat hunting patterns for brute force authentication, suspicious script execution, and egress volume anomalies.
3. Validate queries using the in-terminal and interactive log search workbench.

### Getting Started
Use the **Log Search** tab to type your queries and run them using `Ctrl+Enter`.

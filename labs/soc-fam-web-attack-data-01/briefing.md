# Scenario Practice: Web Application Attacks & SQL Injection

Triage web server access logs, WAF alerts, and application database query logs to distinguish blocked automated vulnerability scanners from successful data extraction and web shell deployment.

### Learning Goals
- Analyze HTTP status codes (200 OK vs 403 Forbidden vs 500 Internal Server Error) to assess attack outcome.
- Identify SQL syntax error patterns, union queries, and path traversal strings in URI queries.
- Correlate web server requests with unauthorized file creations in public document roots.

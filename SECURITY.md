# Security Policy

## Reporting a Vulnerability

We take the security of CyberBLADE seriously. Because CyberBLADE is a platform for teaching offensive and defensive cybersecurity concepts, maintaining a hardened posture is essential.

If you discover a security vulnerability in this application, please report it responsibly:

1. **Email:** Send details to `security@cyberblade.local` (or file a confidential security advisory if hosted on GitHub).
2. **What to include:**
   - A description of the vulnerability and potential impact.
   - Exact steps or minimal proof of concept to reproduce locally against `localhost`.
   - Your contact information so we can coordinate acknowledgment.
3. **Disclosure guidelines:**
   - Please do not test against production or hosted learner accounts.
   - Please give us reasonable time to investigate and patch before public disclosure.
   - We do not currently operate a paid bug bounty program, but we will credit responsible security researchers on our Credits page upon verification.
